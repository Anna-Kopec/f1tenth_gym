Load a map and add one point per obstacle pixel to the batch. 

Each obstacle pixel (value exactly 0) is converted to world metres using the YAML\textquotesingle{}s resolution and origin, then scaled by 50 into drawing units.


\begin{DoxyParams}{Parameters}
{\em map\+\_\+path} & Path to the map {\itshape without} an extension; \textquotesingle{}.yaml\textquotesingle{} and {\ttfamily map\+\_\+ext} are appended to it. \\
\hline
{\em map\+\_\+ext} & Image extension, including the dot.\\
\hline
\end{DoxyParams}
\begin{DoxyNote}{Note}
The origin yaw in the YAML is ignored here (the scan simulator does use it). 

Only pixels that are exactly 0 are drawn. The scan simulator treats everything \texorpdfstring{$<$}{<}= 128 as an obstacle, so grey pixels count as walls but are not drawn. 

Calling this again adds the new points without removing the old ones. 
\end{DoxyNote}
