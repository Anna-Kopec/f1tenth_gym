\doxysubsection{Detailed Description}
Standalone experiment for the pan / zoom camera later used by \doxylink{rendering_8py}{rendering.\+py}: Env\+Renderer. 

Opens an 800x800 window with one coloured square. Drag with the mouse to pan and scroll to zoom about the cursor. The camera logic (left/\+right/\+bottom/\+top bounds plus a gl\+Ortho projection) is the same approach Env\+Renderer uses.

Run with: {\ttfamily python} \doxylink{pyglet__test__camera_8py}{pyglet\+\_\+test\+\_\+camera.\+py} (the window opens as soon as the module is run or imported).
