\doxysubsection{Detailed Description}
Unit tests comparing the KS and ST models against Common\+Road reference values. 

The test vehicle is the full-\/size Common\+Road reference car (converted from imperial units), not the F1\+TENTH car, so the parameters differ greatly from the gym defaults.
