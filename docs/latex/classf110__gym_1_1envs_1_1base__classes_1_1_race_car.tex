\doxysubsection{Detailed Description}
A single simulated vehicle: physics, Li\+DAR, and wall-\/collision detection. 

A \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_race_car}{Race\+Car} owns its own state vector and control inputs, but shares a single Li\+DAR scan simulator (and the per-\/beam lookup tables derived from it) with every other \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_race_car}{Race\+Car} instance. Those shared objects are stored as class attributes and built only once, by whichever car is constructed first.

A \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_race_car}{Race\+Car} only knows about collisions with the static map (walls). Car-\/to-\/car collisions are detected by \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_simulator_a132361ffe37fb81c0bf92c0c6c0ea4d8}{Simulator.\+check\+\_\+collision()}.

{\footnotesize\ttfamily \label{classf110__gym_1_1envs_1_1base__classes_1_1_race_car_acfad31ede2fab6a052009cb585667a7d} 
f110\+\_\+gym.\+envs.\+base\+\_\+classes.\+Race\+Car.\+check\+\_\+ttc (\begin{DoxyParamCaption}\item[{}]{self}{, }\item[{}]{current\+\_\+scan}{}\end{DoxyParamCaption})}



Detect a collision with the environment using instantaneous time-\/to-\/collision (i\+TTC). 

For every beam i: \begin{DoxyVerb}iTTC_i = (range_i - side_distance_i) / (v * cos(angle_i))
\end{DoxyVerb}


i.\+e. the gap between the car body and the obstacle, divided by how fast the car is closing on it along that beam. If any beam has 0 \texorpdfstring{$<$}{<}= i\+TTC \texorpdfstring{$<$}{<} \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_race_car_a34582c2e022315d26bf94aa92b5c8eb3}{ttc\+\_\+thresh}, the car counts as crashed into a wall. When the car is stationary (v == 0), no collision is reported.

On a collision the car is stopped: control inputs are zeroed and so is state\+[3:].

\begin{DoxyWarning}{Warning}
state\+[3:] also includes the yaw angle (index 4), so a crash snaps the car\textquotesingle{}s heading to 0 as well as stopping it. 
\end{DoxyWarning}
\begin{DoxyNote}{Note}
This does NOT detect collisions with other vehicles; see \doxylink{classf110__gym_1_1envs_1_1base__classes_1_1_simulator_a132361ffe37fb81c0bf92c0c6c0ea4d8}{Simulator.\+check\+\_\+collision()}.
\end{DoxyNote}
