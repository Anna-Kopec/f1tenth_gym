\doxysubsection{Detailed Description}
Older standalone prototype of the Li\+DAR simulator. 

Superseded by \doxylink{laser__models_8py}{laser\+\_\+models.\+py}.

This file is kept for reference only; nothing in the gym imports it. It differs from \doxylink{laser__models_8py}{envs/\+laser\+\_\+models.\+py} in these ways:
\begin{DoxyItemize}
\item {\bfseries{Noise:}} Scan\+Simulator2D owns its noise generator and standard deviation ({\ttfamily seed} and {\ttfamily std\+\_\+dev} constructor arguments), and scan(pose) always adds noise. In \doxylink{laser__models_8py}{laser\+\_\+models.\+py} the caller passes a generator, or None for no noise.
\item {\bfseries{No range clipping:}} trace\+\_\+ray() does not clip the result to {\ttfamily max\+\_\+range}, so a beam can come back slightly longer than max\+\_\+range.
\item {\bfseries{Missing functions:}} none of the time-\/to-\/collision or other-\/car ray-\/casting functions (check\+\_\+ttc\+\_\+jit, ray\+\_\+cast, get\+\_\+range, ...) exist here.
\item {\bfseries{Tests:}} they compare scans against legacy\+\_\+scan.\+npz (made by \doxylink{legacy__scan__gen_8py}{legacy\+\_\+scan\+\_\+gen.\+py} from the old C++ simulator), using map paths (\textquotesingle{}../../../\+maps/...\textquotesingle{}) that do not exist in this repository.
\item {\bfseries{Entry point:}} running the file calls main(), not the tests, and main() loads a map from a hard-\/coded path on the original author\textquotesingle{}s machine.
\end{DoxyItemize}

For how the ray tracing works and detailed per-\/function documentation, see \doxylink{laser__models_8py}{laser\+\_\+models.\+py}.
