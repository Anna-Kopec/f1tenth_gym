\doxysubsection{Detailed Description}
F1\+TENTH gym: a lightweight 2D racing simulator with the Open\+AI gym interface. 

Importing this package registers the environment with gym under the id {\ttfamily \textquotesingle{}f110-\/v0\textquotesingle{}}, so it can be created with: 
\begin{DoxyCode}{0}
\DoxyCodeLine{env\ =\ gym.make(\textcolor{stringliteral}{'f110\_gym:f110-\/v0'},\ map=\textcolor{stringliteral}{'vegas'},\ num\_agents=1)}

\end{DoxyCode}
 The {\ttfamily \textquotesingle{}\doxylink{namespacef110__gym}{f110\+\_\+gym}:\textquotesingle{}} prefix makes gym import this package (and so run the registration below) before looking up the id.
