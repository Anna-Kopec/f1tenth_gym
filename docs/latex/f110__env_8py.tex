\doxysubsection{Detailed Description}
Open\+AI gym environment for F1\+TENTH racing (F110\+Env). 

F110\+Env is the public entry point of the package. It wraps base\+\_\+classes.\+Simulator (which does the physics, Li\+DAR and collisions) and adds:
\begin{DoxyItemize}
\item the gym interface: reset() / step() / render();
\item lap counting and lap timing, using a "{}finish zone"{} around the start pose;
\item the episode-\/end (done) condition;
\item rendering through rendering.\+Env\+Renderer.
