Detailed Description

Generate random closed race tracks as gym maps (image + YAML) plus a centreline CSV.

Adapted from the track generator in OpenAI gym's CarRacing-v0.

Usage

python random_trackgen.py --seed 123 --num_maps 5

Output goes into folders created in the current directory:

  • maps/mapN.png and maps/mapN.pgm: the track walls as a black-on-white image.
  • maps/mapN.yaml: map metadata (resolution 0.0625 m/pixel, origin).
  • centerline/mapN.csv: centreline waypoints "x, y" in metres, starting at (0, 0).

How a track is made (create_track())

  1. Place 16 checkpoints around a circle, each at a random angle within its 1/16 sector and a random radius.
  2. "Drive" a point around them: at each step it turns toward the next checkpoint, with a limited turn rate, then moves forward a fixed distance. Every step is recorded.
  3. Cut out exactly one lap: the section between two consecutive passes through the start angle. If its two ends don't meet up cleanly, give up (the caller retries).
  4. Offset the centreline by +/-WIDTH with shapely to get the two walls.

convert_track() then plots the walls with matplotlib and writes the image, YAML and centreline files.

Render a generated track to a gym map and save its files (see the file overview for the outputs).

The two walls are drawn as thick black lines on a white 20 x 20 inch matplotlib figure, saved at 80 dpi (1600 x 1600 pixels), and converted to grayscale with OpenCV.

The world frame is chosen so the first centreline point is at (0, 0). Pixel positions are measured with matplotlib's transData, which works at the figure's own 100 dpi, and scaled by 0.05 m per pixel. At the saved 80 dpi that is 0.05 * 100 / 80 = 0.0625 m per pixel, which is the resolution written to the YAML.

Parameters
tracknp.ndarray of shape (n, 2): centreline from create_track().
track_intnp.ndarray: first wall from create_track().
track_extnp.ndarray: second wall from create_track().
iterMap number, used in the file names (mapN.*).
Note
The 0.05 / 0.0625 relationship relies on matplotlib's default figure dpi of 100. A matplotlibrc that changes it would misalign the centreline and the image.
The "map size" printed is the figure size at 100 dpi, not the saved image size.

◆ create_track()

create_track ( )

Generate one random closed track.

See the file overview for the algorithm. Track units are arbitrary until convert_track() fixes the scale.

Returns
Either a tuple (track_xy, wall_a, wall_b) of np.ndarrays of (x, y) points:
  • track_xy: the centreline, shape (n, 2).
  • wall_a: the centreline grown outward by WIDTH (outer wall).
  • wall_b: the centreline shrunk inward by WIDTH (inner wall). Or False if this attempt failed to make a clean closed loop.
Note
The returned walls are named track_xy_offset_in / _out in the code, but buffer(+WIDTH) is actually the outer wall and buffer(-WIDTH) the inner one.
