waypoint_follow.PurePursuitPlanner._get_current_waypoint ( self,
waypoints,
lookahead_distance,

protected

Choose the point to aim for.

  • If the car is within lookahead_distance of the raceline: the raceline point one lookahead distance ahead (see the note).
  • If it is further away but within max_reacquire (20 m): the nearest raceline segment's start point, to steer back onto the line.
  • Otherwise: None.
Parameters
waypointsFull raceline array (all columns), used for the speed column.
lookahead_distanceLookahead distance (m).
positionnp.ndarray of shape (2,): car position.
thetaCar yaw (unused).
Returns
np.ndarray of shape (3,): [x, y, target speed], or None.
Note
The point returned is the start waypoint of the segment where the lookahead circle crosses, not the exact crossing point. The speed is taken from the waypoint nearest the car.
