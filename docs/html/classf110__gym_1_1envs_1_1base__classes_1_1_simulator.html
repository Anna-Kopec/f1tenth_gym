Detailed Description

Multi-vehicle world: owns every RaceCar and steps them together.

The Simulator handles what a single RaceCar cannot do alone: stepping all cars together, detecting car-to-car collisions, and making cars visible in each other's LiDAR scans. F110Env wraps this class and adds lap counting, rendering and the gym interface on top.

◆ check_collision()

f110_gym.envs.base_classes.Simulator.check_collision ( self)

Detect car-to-car collisions with the GJK algorithm.

Each car is modelled as a length x width rectangle at its current pose. Every pair of rectangles is tested for overlap with GJK (Gilbert-Johnson-Keerthi), a fast test for intersecting convex shapes.

Overwrites collisions and collision_idx. Wall collisions are added to collisions afterwards in step().

◆ step()

f110_gym.envs.base_classes.Simulator.step ( self,
control_inputs )

Advance the whole world by one physics time step.

The steps are:

  1. Move every car (RaceCar.update_pose) and record its new pose. Each car also takes a scan against the static map.
  2. Check car-to-car collisions on the new poses (check_collision).
  3. For each car: give it the other cars' poses, check for a wall collision, and add the other cars to its scan (RaceCar.update_scan). A wall collision also sets that car's entry in collisions.
  4. Build and return the observation dictionary.
Parameters
control_inputsnp.ndarray of shape (num_agents, 2). Row i is [desired steering angle (rad), desired speed (m/s)] for car i.
Returns
Observation dictionary with keys:
  • ego_idx index of the ego vehicle
  • scans list of LiDAR scans, each np.ndarray of shape (num_beams,)
  • poses_x list of x positions (m)
  • poses_y list of y positions (m)
  • poses_theta list of yaw angles (rad)
  • linear_vels_x list of longitudinal speeds (m/s)
  • linear_vels_y list of lateral speeds. Always 0; this is not simulated.
  • ang_vels_z list of yaw rates (rad/s)
  • collisions np.ndarray of collision flags (1.0 = collided)
