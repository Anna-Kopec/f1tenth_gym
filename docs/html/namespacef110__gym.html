Detailed Description

F1TENTH gym: a lightweight 2D racing simulator with the OpenAI gym interface.

Importing this package registers the environment with gym under the id 'f110-v0', so it can be created with:

env = gym.make('f110_gym:f110-v0', map='vegas', num_agents=1)

The 'f110_gym:' prefix makes gym import this package (and so run the registration below) before looking up the id.

See also
f110_env.py: F110Env for the keyword arguments and the step / reset interface.
