Detailed Description

A single simulated vehicle: physics, LiDAR, and wall-collision detection.

A RaceCar owns its own state vector and control inputs, but shares a single LiDAR scan simulator (and the per-beam lookup tables derived from it) with every other RaceCar instance. Those shared objects are stored as class attributes and built only once, by whichever car is constructed first.

A RaceCar only knows about collisions with the static map (walls). Car-to-car collisions are detected by Simulator.check_collision().

See also
Simulator for how multiple RaceCars are stepped together.

current_scan )

Detect a collision with the environment using instantaneous time-to-collision (iTTC).

For every beam i: 

iTTC_i = (range_i - side_distance_i) / (v * cos(angle_i))

i.e. the gap between the car body and the obstacle, divided by how fast the car is closing on it along that beam. If any beam has 0 <= iTTC < ttc_thresh, the car counts as crashed into a wall. When the car is stationary (v == 0), no collision is reported.

On a collision the car is stopped: control inputs are zeroed and so is state[3:].

Warning
state[3:] also includes the yaw angle (index 4), so a crash snaps the car's heading to 0 as well as stopping it.
Note
This does NOT detect collisions with other vehicles; see Simulator.check_collision().
Parameters
current_scannp.ndarray of shape (num_beams,): LiDAR ranges to check.
Returns
True if the car is in collision with the environment.

f110_gym.envs.base_classes.RaceCar.update_pose ( self,
raw_steer,
vel )

Advance the vehicle's physics one time step and take a LiDAR scan.

The steps are:

  1. Steering delay: raw_steer goes into a FIFO buffer, and the command from steer_buffer_size steps ago comes out. Until the buffer is full, the applied steering is 0.
  2. Low-level control: pid() converts the desired steering angle and speed into a steering velocity and an acceleration. Steering is bang-bang at +/- sv_max until the target angle is reached. Acceleration is proportional to the speed error and capped at a_max.
  3. Integration: the single-track (bicycle) model with tyre slip, vehicle_dynamics_st(), gives the state derivative, which is integrated over one time_step with Euler or RK4.
  4. Yaw wrap: heading is wrapped into [0, 2*pi].
  5. LiDAR scan: a noisy scan is ray-cast against the static map from the LiDAR position (lidar_dist ahead of the reference point).
Parameters
raw_steerDesired front-wheel steering angle (rad).
velDesired longitudinal speed (m/s).
Returns
np.ndarray of shape (num_beams,): LiDAR scan against the static map only. Other vehicles are added later by update_scan().
Exceptions
SyntaxErrorIf integrator is not a supported Integrator value.

f110_gym.envs.base_classes.RaceCar.update_scan ( self,
agent_scans,
agent_index )

Finish this vehicle's scan: check for a wall collision, then add the opponents.

This is separate from update_pose() because ray-casting opponents needs the new poses of every car, so all cars must move before any scan is finished.

The iTTC check runs on the map-only scan, before opponents are added. That way another car close by is not mistaken for a wall collision; car-to-car contact is handled separately by Simulator.check_collision().

Parameters
agent_scansList of every car's scan. Entry agent_index is replaced with the finished scan.
agent_indexIndex of this car in agent_scans.
