Detailed Description

Older standalone prototype of the vehicle dynamics.

Superseded by dynamic_models.py.

This file is kept for reference only; nothing in the gym imports it. It differs from envs/dynamic_models.py in two ways:

  • vehicle_dynamics_st() switches to the kinematic model below 0.1 m/s (dynamic_models.py uses 0.5 m/s).
  • pid() is an empty stub that returns None. The working speed/steering controller is dynamic_models.py: pid().

For the model equations, parameter table and detailed per-function documentation, see dynamic_models.py.

Run the tests with: python dynamics_test.py
