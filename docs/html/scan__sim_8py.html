Detailed Description

Older standalone prototype of the LiDAR simulator.

Superseded by laser_models.py.

This file is kept for reference only; nothing in the gym imports it. It differs from envs/laser_models.py in these ways:

  • Noise: ScanSimulator2D owns its noise generator and standard deviation (seed and std_dev constructor arguments), and scan(pose) always adds noise. In laser_models.py the caller passes a generator, or None for no noise.
  • No range clipping: trace_ray() does not clip the result to max_range, so a beam can come back slightly longer than max_range.
  • Missing functions: none of the time-to-collision or other-car ray-casting functions (check_ttc_jit, ray_cast, get_range, ...) exist here.
  • Tests: they compare scans against legacy_scan.npz (made by legacy_scan_gen.py from the old C++ simulator), using map paths ('../../../maps/...') that do not exist in this repository.
  • Entry point: running the file calls main(), not the tests, and main() loads a map from a hard-coded path on the original author's machine.

For how the ray tracing works and detailed per-function documentation, see laser_models.py.
