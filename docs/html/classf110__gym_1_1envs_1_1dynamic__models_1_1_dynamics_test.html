Detailed Description

Unit tests comparing the KS and ST models against CommonRoad reference values.

The test vehicle is the full-size CommonRoad reference car (converted from imperial units), not the F1TENTH car, so the parameters differ greatly from the gym defaults.

Run with: python dynamic_models.py
