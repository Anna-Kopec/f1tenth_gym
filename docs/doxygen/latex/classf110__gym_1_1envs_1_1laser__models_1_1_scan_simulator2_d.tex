Load a map (YAML + image), binarise it, and compute its distance transform. 

The image path is the YAML path with its extension replaced by {\ttfamily map\+\_\+ext}. The YAML\textquotesingle{}s own {\ttfamily image} field is ignored, so the image must sit next to the YAML with the same base name. The image is:
\begin{DoxyItemize}
\item flipped vertically, so row 0 is the bottom of the map, matching the world y axis;
\item thresholded at 128: pixels \texorpdfstring{$<$}{<}= 128 become obstacles (0) and brighter pixels free space (255).
\end{DoxyItemize}

From the YAML only {\ttfamily resolution} and {\ttfamily origin} (\+[x, y, yaw]) are read.


\begin{DoxyParams}{Parameters}
{\em map\+\_\+path} & Path to the map YAML file. \\
\hline
{\em map\+\_\+ext} & Image extension {\itshape including the dot}, e.\+g. "{}.\+png"{} or "{}.\+pgm"{}. \\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
Always True.
\end{DoxyReturn}
\begin{DoxyNote}{Note}
If the YAML fails to parse, the error is printed and the method carries on, failing later with an Attribute\+Error on {\ttfamily self.\+origin}. 
\end{DoxyNote}
