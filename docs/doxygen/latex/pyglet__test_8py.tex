\doxysubsection{Detailed Description}
Standalone experiment: draw a map\textquotesingle{}s obstacle pixels as points in a pyglet window. 

Loads a map (YAML + image) the same way \doxylink{rendering_8py}{rendering.\+py}: Env\+Renderer.\+update\+\_\+map() does, converts every pure-\/black pixel to a world-\/coordinate point, and draws them with a 3D perspective projection. It also contains two small 2D camera classes (Camera, Centered\+Camera).

Usage: 
\begin{DoxyCode}{0}
\DoxyCodeLine{python\ pyglet\_test.py\ -\/-\/map\_path\ ../envs/maps/vegas\ -\/-\/map\_ext\ .png}

\end{DoxyCode}


\begin{DoxyNote}{Note}
The Camera classes use {\ttfamily window.\+view}, which only exists in pyglet 2.\+x, while the drawing code uses the pyglet 1.\+x batch.\+add() format. setup.\+py pins pyglet \texorpdfstring{$<$}{<} 1.\+5, so the script is unlikely to run unchanged with either version. 
\end{DoxyNote}
