\doxysubsection{Detailed Description}
pyglet / Open\+GL renderer for the F1\+TENTH gym (Env\+Renderer). 

\hypertarget{rendering_8py_rendering_coords}{}\doxysubsection{\texorpdfstring{Drawing coordinates}{Drawing coordinates}}\label{rendering_8py_rendering_coords}
Everything is drawn in a "{}pixel world"{} frame, which is world metres multiplied by 50. The camera is an orthographic projection whose bounds (left, right, bottom, top) change as you pan and zoom. Zooming changes how many of these units fit in the window. The text label sits at a fixed position in this frame, so it moves with the map rather than staying fixed on screen.\hypertarget{rendering_8py_rendering_drawn}{}\doxysubsection{\texorpdfstring{What is drawn}{What is drawn}}\label{rendering_8py_rendering_drawn}

\begin{DoxyItemize}
\item {\bfseries{Map:}} one grey point for every obstacle pixel in the map image.
\item {\bfseries{Cars:}} a filled rectangle per car. The ego car is drawn in a brighter purple.
\item {\bfseries{Label:}} lap time and ego lap count.
\item {\bfseries{FPS counter:}} in the bottom-\/left corner.
\end{DoxyItemize}

Everything except the FPS counter is held in one pyglet Batch, so it is drawn in a single call. Extra shapes can be added to {\ttfamily batch} from F110\+Env render callbacks.
