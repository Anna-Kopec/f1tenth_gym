\doxysubsection{Detailed Description}
Example: a pure pursuit controller following a raceline in the F1\+TENTH gym. 

Loads config\+\_\+example\+\_\+map.\+yaml, creates a single-\/car environment on the example map, and drives one episode with Pure\+Pursuit\+Planner, rendering as it goes. The camera follows the car and the waypoints are drawn on the map.

Run it from the {\ttfamily examples} folder, because the config and waypoint paths are relative: 
\begin{DoxyCode}{0}
\DoxyCodeLine{cd\ examples}
\DoxyCodeLine{python\ waypoint\_follow.py}

\end{DoxyCode}
\hypertarget{waypoint__follow_8py_waypoint_follow_pure_pursuit}{}\doxysubsection{\texorpdfstring{How pure pursuit works}{How pure pursuit works}}\label{waypoint__follow_8py_waypoint_follow_pure_pursuit}
Each step, the controller:
\begin{DoxyEnumerate}
\item finds the point on the raceline nearest the car;
\item walks forward along the raceline to the first point that is the {\itshape lookahead distance} L away from the car, and aims for it;
\item fits the circular arc that leaves the car along its heading and passes through that point. If the point is a lateral (sideways) distance y from the car\textquotesingle{}s heading line, the arc has radius R = L\texorpdfstring{$^\wedge$}{\string^}2 / (2y);
\item steers with the bicycle-\/model angle for that arc: delta = atan(wheelbase / R). The speed command is the raceline\textquotesingle{}s speed at the nearest point, times a gain.
\end{DoxyEnumerate}

A longer lookahead gives smoother but wider lines; a shorter one tracks more tightly but can oscillate.\hypertarget{waypoint__follow_8py_waypoint_follow_config}{}\doxysubsection{\texorpdfstring{Config file fields used}{Config file fields used}}\label{waypoint__follow_8py_waypoint_follow_config}

First point along the trajectory, searching forward from {\ttfamily t}, that is exactly {\ttfamily radius} from {\ttfamily point}. 

Each segment start + s \texorpdfstring{$\ast$}{*} V is tested against the circle \texorpdfstring{$\vert$}{|}start + s \texorpdfstring{$\ast$}{*} V -\/ point\texorpdfstring{$\vert$}{|} = radius. That is a quadratic in s, and a root with s in \+[0, 1] is a crossing on the segment. On the starting segment, only crossings at or after the starting fraction count.

Algorithm: \href{http://codereview.stackexchange.com/questions/86421/line-segment-to-circle-collision-algorithm}{\texttt{http:\+/\+/\+codereview.\+stackexchange.\+com/\+questions/\+86421/\+line-\/segment-\/to-\/circle-\/collision-\/algorithm}}

main (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Run one episode of pure pursuit on the example map, rendering in real time. 

Steps:
\begin{DoxyEnumerate}
\item Load config\+\_\+example\+\_\+map.\+yaml.
\item Build the planner with the default F1\+TENTH wheelbase (lf + lr = 0.\+15875 + 0.\+17145 m).
\item Create a 1-\/car env with the RK4 integrator and register a render callback. The callback makes the camera follow the car and draws the raceline.
\item Reset at the configured start pose, then step until done: the car crashes or completes 2 laps.
\item Print simulated time against real time.
\end{DoxyEnumerate}

Nearest point to {\ttfamily point} on a piecewise-\/linear trajectory. 

Projects the point onto every segment (clamped to the segment\textquotesingle{}s ends) and returns the closest projection. It is fast: about 0.\+2 ms for 1000 waypoints.
