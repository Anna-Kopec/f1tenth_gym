\doxysubsection{Detailed Description}
Car-\/to-\/car collision detection (2D GJK) and helpers for vehicle body geometry. 

\hypertarget{collision__models_8py_collision_models_gjk_overview}{}\doxysubsection{\texorpdfstring{How the GJK collision test works}{How the GJK collision test works}}\label{collision__models_8py_collision_models_gjk_overview}
GJK (Gilbert-\/\+Johnson-\/\+Keerthi) decides whether two convex shapes overlap without testing their edges against each other directly. It relies on one fact:

\begin{quote}
Two convex shapes A and B overlap if and only if their Minkowski difference A -\/ B = \{ a -\/ b : a in A, b in B \} contains the origin. \end{quote}


The Minkowski difference is never built explicitly. Instead, a {\itshape support function} returns its furthest point in any requested direction. The algorithm grows a simplex (a point, then a line segment, then a triangle in 2D) from support points, each time searching in the direction of the origin:
\begin{DoxyItemize}
\item If a new support point fails to get past the origin in the search direction, the origin cannot be inside A -\/ B, so the shapes are separated.
\item If the triangle ever encloses the origin, the shapes overlap.
\end{DoxyItemize}

The implementation is a port of \href{https://github.com/kroitor/gjk.c}{\texttt{https:\+/\+/\+github.\+com/\+kroitor/\+gjk.\+c}}. Every function is compiled with numba ({\ttfamily njit}) for speed.\hypertarget{collision__models_8py_collision_models_vertex_helpers}{}\doxysubsection{\texorpdfstring{Vehicle geometry helpers}{Vehicle geometry helpers}}\label{collision__models_8py_collision_models_vertex_helpers}
get\+\_\+trmtx() and get\+\_\+vertices() turn a pose \+[x, y, yaw] plus a body length and width into the four world-\/frame corners of the car\textquotesingle{}s rectangle. Both the Simulator (for collisions) and the renderer (for drawing) use them.
