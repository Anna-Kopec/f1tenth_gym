\doxysubsection{Detailed Description}
Older standalone prototype of the GJK collision code. 

Superseded by \doxylink{collision__models_8py}{collision\+\_\+models.\+py}.

This file is kept for reference only; nothing in the gym imports it. Its functions are identical to the ones in \doxylink{collision__models_8py}{envs/\+collision\+\_\+models.\+py}, except that it has {\bfseries{no collision\+\_\+multiple()}} (the pairwise check across many cars that the Simulator uses) and no test for it.

For how GJK works and detailed per-\/function documentation, see \doxylink{collision__models_8py}{collision\+\_\+models.\+py}.

Run the tests with: {\ttfamily python} \doxylink{collision__checks_8py}{collision\+\_\+checks.\+py} (test\+\_\+get\+\_\+vert opens a matplotlib window and blocks until it is closed).
