\doxysubsection{Detailed Description}
Script that generated legacy\+\_\+scan.\+npz: reference Li\+DAR scans from the old C++-\/backed gym. 

For each of three maps (vegas, berlin, skirk), it resets the old environment at 10 test poses (at the origin, yaw from -\/1 to 1 rad) and records the ego car\textquotesingle{}s 1080-\/beam scan. The scans are saved to legacy\+\_\+scan.\+npz under the keys {\ttfamily vegas}, {\ttfamily berlin} and {\ttfamily skirk}, and \doxylink{scan__sim_8py}{scan\+\_\+sim.\+py}\textquotesingle{}s tests compare against them.

\begin{DoxyWarning}{Warning}
This script uses the {\bfseries{old}} gym API (init\+\_\+map(), update\+\_\+params() with a C++ executable directory, reset() with a dict of poses), which the current F110\+Env does not have, and paths to a C++ build and maps that are not in this repository. It is kept as a record of how the data was made and will not run as-\/is.
\end{DoxyWarning}
