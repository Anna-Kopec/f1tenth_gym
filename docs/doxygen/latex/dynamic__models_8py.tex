\doxysubsection{Detailed Description}
Vehicle dynamics for the F1\+TENTH gym: single-\/track (bicycle) models, input constraints, and the low-\/level speed / steering controller. 

Follows the Common\+Road single-\/track vehicle models. Original implementation: \href{https://gitlab.lrz.de/tum-cps/commonroad-vehicle-models/}{\texttt{https:\+/\+/\+gitlab.\+lrz.\+de/\+tum-\/cps/\+commonroad-\/vehicle-\/models/}}\hypertarget{dynamic__models_8py_dynamic_models_models}{}\doxysubsection{\texorpdfstring{Models in this file}{Models in this file}}\label{dynamic__models_8py_dynamic_models_models}

\begin{DoxyItemize}
\item {\bfseries{Kinematic single-\/track (KS)}}, vehicle\+\_\+dynamics\+\_\+ks(): a 5-\/state bicycle model with no tyre slip. The wheels go exactly where they point. Accurate at low speed, wrong when cornering hard.
\item {\bfseries{Dynamic single-\/track (ST)}}, vehicle\+\_\+dynamics\+\_\+st(): a 7-\/state bicycle model with a linear tyre model, slip angle and yaw dynamics, including load transfer from longitudinal acceleration. Below 0.\+5 m/\+s it switches to the KS equations, because the ST equations divide by the speed.
\end{DoxyItemize}

Both functions return the state {\itshape derivative} f(x, u). They do not step the state themselves; an integrator (Euler or RK4 in base\+\_\+classes.\+Race\+Car.\+update\+\_\+pose) does that.\hypertarget{dynamic__models_8py_dynamic_models_inputs}{}\doxysubsection{\texorpdfstring{Control inputs}{Control inputs}}\label{dynamic__models_8py_dynamic_models_inputs}
The models take u = \+[steering angle velocity, longitudinal acceleration]. The gym\textquotesingle{}s users command a {\itshape desired steering angle and speed} instead, so pid() converts between the two. Every model call first passes u through steering\+\_\+constraint() and accl\+\_\+constraints() to enforce the physical limits.\hypertarget{dynamic__models_8py_dynamic_models_params}{}\doxysubsection{\texorpdfstring{Vehicle parameters (shared by every function)}{Vehicle parameters (shared by every function)}}\label{dynamic__models_8py_dynamic_models_params}

Low-\/level controller: desired (speed, steering angle) -\/\texorpdfstring{$>$}{>} (acceleration, steering velocity). 

This is what lets the gym take "{}go this fast, steer this much"{} as its action.

{\bfseries{Steering (bang-\/bang):}} if the steering angle is off target by more than 1e-\/4 rad, steer toward the target at full rate (+/\+-\/ {\ttfamily max\+\_\+sv}). Otherwise hold still. The angle can overshoot by up to max\+\_\+sv \texorpdfstring{$\ast$}{*} dt in one step.

{\bfseries{Speed (proportional only, no integral or derivative term):}} acceleration = kp \texorpdfstring{$\ast$}{*} (target speed -\/ current speed). The gain kp depends on the situation:


\begin{DoxyTable}{4}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Current speed  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Speed error  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Situation  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}kp  \\
forward (v \texorpdfstring{$>$}{>} 0)  &positive  &speeding up  &10 \texorpdfstring{$\ast$}{*} max\+\_\+a / max\+\_\+v  \\
forward (v \texorpdfstring{$>$}{>} 0)  &zero or negative  &braking  &10 \texorpdfstring{$\ast$}{*} max\+\_\+a / (-\/min\+\_\+v)  \\
v \texorpdfstring{$<$}{<}= 0  &positive  &braking  &2 \texorpdfstring{$\ast$}{*} max\+\_\+a / max\+\_\+v  \\
v \texorpdfstring{$<$}{<}= 0  &zero or negative  &speeding up  &2 \texorpdfstring{$\ast$}{*} max\+\_\+a / (-\/min\+\_\+v)  \\
\end{DoxyTable}


A car at a standstill (v == 0) uses the v \texorpdfstring{$<$}{<}= 0 rows, so pulling away from rest uses the gentler gain of 2 rather than 10.

Outputs are not clamped here. accl\+\_\+constraints() and steering\+\_\+constraint() clamp them inside the dynamics model.

Kinematic single-\/track (bicycle) model: state derivative f(x, u). 

It assumes the tyres roll without slipping, so the rear axle always moves along the car\textquotesingle{}s heading and the yaw rate is set purely by geometry: \begin{DoxyVerb}x_dot     = v * cos(psi)
y_dot     = v * sin(psi)
delta_dot = u[0]  (steering velocity)
v_dot     = u[1]  (acceleration)
psi_dot   = v / (lf + lr) * tan(delta)
\end{DoxyVerb}


Here (x, y) is the rear-\/axle position.

Dynamic single-\/track (bicycle) model with tyre slip: state derivative f(x, u). 

{\bfseries{Above 0.\+5 m/\+s}} (the dynamic model):
\begin{DoxyItemize}
\item Position moves along the {\itshape velocity} direction, psi + beta, not the heading psi. The car can drift sideways.
\item Each axle\textquotesingle{}s lateral tyre force is linear in its slip angle. The force is scaled by mu, by that axle\textquotesingle{}s cornering stiffness (C\+\_\+\+Sf or C\+\_\+\+Sr) and by the axle\textquotesingle{}s normal load.
\item Normal loads include longitudinal load transfer. The front axle carries m\texorpdfstring{$\ast$}{*}(g\texorpdfstring{$\ast$}{*}lr -\/ a\texorpdfstring{$\ast$}{*}h)/(lf + lr) and the rear axle m\texorpdfstring{$\ast$}{*}(g\texorpdfstring{$\ast$}{*}lf + a\texorpdfstring{$\ast$}{*}h)/(lf + lr), so accelerating (a \texorpdfstring{$>$}{>} 0) shifts load to the rear and braking shifts it to the front.
\item The yaw acceleration (x\+[5] derivative) and slip angle rate (x\+[6] derivative) come from the lateral force and moment balance on these tyre forces.
\end{DoxyItemize}

{\bfseries{Below 0.\+5 m/\+s}} (kinematic fallback): the dynamic equations divide by v and v\texorpdfstring{$^\wedge$}{\string^}2, so they blow up near standstill. The KS model is used instead for the first five states, and:
\begin{DoxyItemize}
\item the yaw rate derivative is the time derivative of the KS yaw rate, d/\+dt \+[ v / lwb \texorpdfstring{$\ast$}{*} tan(delta) ] = a/\+lwb \texorpdfstring{$\ast$}{*} tan(delta) + v/(lwb \texorpdfstring{$\ast$}{*} cos\texorpdfstring{$^\wedge$}{\string^}2(delta)) \texorpdfstring{$\ast$}{*} delta\+\_\+dot.
\item the slip angle derivative is 0, so the slip angle is held constant.
\end{DoxyItemize}
