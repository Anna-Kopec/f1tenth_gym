\doxysubsection{Detailed Description}
Older standalone prototype of the vehicle dynamics. 

Superseded by \doxylink{dynamic__models_8py}{dynamic\+\_\+models.\+py}.

This file is kept for reference only; nothing in the gym imports it. It differs from \doxylink{dynamic__models_8py}{envs/\+dynamic\+\_\+models.\+py} in two ways:
\begin{DoxyItemize}
\item vehicle\+\_\+dynamics\+\_\+st() switches to the kinematic model below {\bfseries{0.\+1 m/\+s}} (\doxylink{dynamic__models_8py}{dynamic\+\_\+models.\+py} uses 0.\+5 m/\+s).
\item pid() is an {\bfseries{empty stub}} that returns None. The working speed/\+steering controller is \doxylink{dynamic__models_8py}{dynamic\+\_\+models.\+py}: pid().
\end{DoxyItemize}

For the model equations, parameter table and detailed per-\/function documentation, see \doxylink{dynamic__models_8py}{dynamic\+\_\+models.\+py}.

Run the tests with: {\ttfamily python} \doxylink{dynamics__test_8py}{dynamics\+\_\+test.\+py}
