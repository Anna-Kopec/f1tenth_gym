Detailed Description

Example: a pure pursuit controller following a raceline in the F1TENTH gym.

Loads config_example_map.yaml, creates a single-car environment on the example map, and drives one episode with PurePursuitPlanner, rendering as it goes. The camera follows the car and the waypoints are drawn on the map.

Run it from the examples folder, because the config and waypoint paths are relative:

cd examples
python waypoint_follow.py

How pure pursuit works

Each step, the controller:

  1. finds the point on the raceline nearest the car;
  2. walks forward along the raceline to the first point that is the lookahead distance L away from the car, and aims for it;
  3. fits the circular arc that leaves the car along its heading and passes through that point. If the point is a lateral (sideways) distance y from the car's heading line, the arc has radius R = L^2 / (2y);
  4. steers with the bicycle-model angle for that arc: delta = atan(wheelbase / R). The speed command is the raceline's speed at the nearest point, times a gain.

A longer lookahead gives smoother but wider lines; a shorter one tracks more tightly but can oscillate.

First point along the trajectory, searching forward from t, that is exactly radius from point.

Each segment start + s * V is tested against the circle |start + s * V - point| = radius. That is a quadratic in s, and a root with s in [0, 1] is a crossing on the segment. On the starting segment, only crossings at or after the starting fraction count.

Algorithm: http://codereview.stackexchange.com/questions/86421/line-segment-to-circle-collision-algorithm

Parameters
pointnp.ndarray of shape (2,): circle centre (the car's position).
radiusCircle radius (the lookahead distance) (m).
trajectorynp.ndarray of shape (N, 2): waypoints [x, y].
tWhere to start searching: segment index plus fraction along it (e.g. 12.3 = 30% along segment 12), as given by nearest_point_on_trajectory().
wrapIf True and nothing is found before the end, continue from the start of the trajectory, treating it as a closed loop.
Returns
Tuple (point, segment_index, fraction), or (None, None, None) if there is no crossing.
Note
The search assumes the starting segment passes within radius of point.
A tiny 1e-6 is added to each segment's end point to avoid zero-length segments.

Pure pursuit control law: speed and steering angle toward a lookahead point.

◆ main()

main ( )

Run one episode of pure pursuit on the example map, rendering in real time.

Steps:

  1. Load config_example_map.yaml.
  2. Build the planner with the default F1TENTH wheelbase (lf + lr = 0.15875 + 0.17145 m).
  3. Create a 1-car env with the RK4 integrator and register a render callback. The callback makes the camera follow the car and draws the raceline.
  4. Reset at the configured start pose, then step until done: the car crashes or completes 2 laps.
  5. Print simulated time against real time.

The work dict holds tuned controller values: tlad is the lookahead distance (m) and vgain the speed gain. mass and lf are left over from the tuning run and are not used.

Nearest point to point on a piecewise-linear trajectory.

Projects the point onto every segment (clamped to the segment's ends) and returns the closest projection. It is fast: about 0.2 ms for 1000 waypoints.

Parameters
pointnp.ndarray of shape (2,): query point [x, y].
trajectorynp.ndarray of shape (N, 2): waypoints [x, y]. Consecutive waypoints must differ, or a zero-length segment causes a division by zero.
Returns
Tuple (projection, distance, t, segment_index):
  • projection: np.ndarray of shape (2,), the nearest point on the trajectory.
  • distance: distance from point to it.
  • t: position along that segment, from 0 (start) to 1 (end).
  • segment_index: index i of the segment, which runs from waypoint i to waypoint i+1.
