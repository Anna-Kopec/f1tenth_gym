Detailed Description

2D LiDAR simulator: holds a map and its distance transform, and produces noisy scans.

Usage:

sim = ScanSimulator2D(num_beams=1080, fov=4.7)
sim.set_map('maps/vegas.yaml', '.png')
ranges = sim.scan(np.array([x, y, yaw]), np.random.default_rng(0))

Parameters
num_beamsNumber of beams per scan.
fovField of view (rad). Beams are evenly spaced from -fov/2 to +fov/2.
epsSphere-tracing stop tolerance (m): a ray counts as hitting something once it is this close to an obstacle.
theta_disNumber of discrete angles in the 0 to 2*pi lookup table. A larger value gives more precise beam directions.
max_rangeMaximum LiDAR range (m).
Note
The table is built with np.linspace(0, 2*pi, theta_dis), which includes both endpoints, so its spacing is 2*pi/(theta_dis-1). Indices are computed as if the spacing were 2*pi/theta_dis. The resulting angle error is at most one table step (about 0.18 degrees at the default).

Load a map (YAML + image), binarise it, and compute its distance transform.

The image path is the YAML path with its extension replaced by map_ext. The YAML's own image field is ignored, so the image must sit next to the YAML with the same base name. The image is:

  • flipped vertically, so row 0 is the bottom of the map, matching the world y axis;
  • thresholded at 128: pixels <= 128 become obstacles (0) and brighter pixels free space (255).

From the YAML only resolution and origin ([x, y, yaw]) are read.

Parameters
map_pathPath to the map YAML file.
map_extImage extension including the dot, e.g. ".png" or ".pgm".
Returns
Always True.
Note
If the YAML fails to parse, the error is printed and the method carries on, failing later with an AttributeError on self.origin.
