Detailed Description

Older standalone prototype of the GJK collision code.

Superseded by collision_models.py.

This file is kept for reference only; nothing in the gym imports it. Its functions are identical to the ones in envs/collision_models.py, except that it has no collision_multiple() (the pairwise check across many cars that the Simulator uses) and no test for it.

For how GJK works and detailed per-function documentation, see collision_models.py.

Run the tests with: python collision_checks.py (test_get_vert opens a matplotlib window and blocks until it is closed).
