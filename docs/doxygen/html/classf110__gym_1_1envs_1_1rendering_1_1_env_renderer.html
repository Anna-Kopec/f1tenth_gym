Detailed Description

pyglet window that draws the environment and handles panning, zooming and resizing.

F110Env.render() creates and drives it: update_obs(), then any render callbacks, then dispatch_events(), on_draw() and flip().

◆ update_map()

f110_gym.envs.rendering.EnvRenderer.update_map ( self,
map_path,
map_ext )

Load a map and add one point per obstacle pixel to the batch.

Each obstacle pixel (value exactly 0) is converted to world metres using the YAML's resolution and origin, then scaled by 50 into drawing units.

Parameters
map_pathPath to the map without an extension; '.yaml' and map_ext are appended to it.
map_extImage extension, including the dot.
Note
The origin yaw in the YAML is ignored here (the scan simulator does use it).
Only pixels that are exactly 0 are drawn. The scan simulator treats everything <= 128 as an obstacle, so grey pixels count as walls but are not drawn.
Calling this again adds the new points without removing the old ones.
