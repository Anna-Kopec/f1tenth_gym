Detailed Description

Test planner that flips its steering left and right to stress the integrator and dynamics.

For testing only. It was used to expose numerical errors when the dynamic (slip) model is active at low speed.

Note
counter is never incremented, so the steering flips on every call regardless of flip_every. The default steer of 2 rad is far beyond the car's steering limit, so the steering simply swings between its limits.
