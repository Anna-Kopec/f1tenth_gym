Detailed Description

Standalone experiment: draw a map's obstacle pixels as points in a pyglet window.

Loads a map (YAML + image) the same way rendering.py: EnvRenderer.update_map() does, converts every pure-black pixel to a world-coordinate point, and draws them with a 3D perspective projection. It also contains two small 2D camera classes (Camera, CenteredCamera).

Usage:

python pyglet_test.py --map_path ../envs/maps/vegas --map_ext .png
Note
The Camera classes use window.view, which only exists in pyglet 2.x, while the drawing code uses the pyglet 1.x batch.add() format. setup.py pins pyglet < 1.5, so the script is unlikely to run unchanged with either version.
