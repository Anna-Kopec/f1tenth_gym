Detailed Description

OpenAI gym environment for F1TENTH.

Create it with gym.make('f110_gym:f110-v0', **kwargs). All keyword arguments are optional:

kwarg Default Meaning
seed 12345 Seed for the LiDAR noise generators.
map (vegas) 'berlin', 'skirk' or 'levine' for a bundled map, or a path to a custom map's YAML file without the .yaml extension. If omitted, the bundled vegas map is used.
map_ext '.png' Map image extension, including the dot ('.png', '.pgm').
params F1TENTH defaults Vehicle parameter dict (see below).
num_agents 2 Number of cars.
timestep 0.01 Physics time step (s).
ego_idx 0 Index of the ego car.
integrator Integrator.RK4 Integrator.RK4 or Integrator.Euler.
lidar_dist 0.0 Forward offset of the LiDAR from the vehicle reference point (m).

Vehicle parameters (params dict):

  • mu: surface friction coefficient
  • C_Sf, C_Sr: front / rear cornering stiffness coefficients
  • lf, lr: distance from the centre of gravity to the front / rear axle (m)
  • h: height of the centre of gravity (m)
  • m: total mass (kg)
  • I: yaw moment of inertia (kg m^2)
  • s_min, s_max: steering angle limits (rad)
  • sv_min, sv_max: steering velocity limits (rad/s)
  • v_switch: speed above which acceleration is power-limited (m/s)
  • a_max: maximum longitudinal acceleration (m/s^2)
  • v_min, v_max: speed limits (m/s)
  • width, length: body size (m), used for collisions and opponent ray casting

Action: np.ndarray of shape (num_agents, 2). Row i is [desired steering angle (rad), desired speed (m/s)] for car i.

Observation: the dict from Simulator.step(), plus lap_times and lap_counts.

Note
The renderer, latest observation and render callbacks are class attributes, so they are shared by every F110Env instance in the process.

◆ _check_done()

f110_gym.envs.f110_env.F110Env._check_done ( self)
protected

Update lap counts and times, and decide whether the episode is over.

Finish zone: each car's position is expressed relative to its own start position, in a frame aligned with the ego car's starting heading:

  • forward (along the start heading): dx
  • sideways: dy, but anything within +/-2 m counts as 0, and beyond that only the excess over 2 m counts.

A car is "in the zone" when dx^2 + (excess dy)^2 <= 0.1. That is roughly a box about 0.63 m long (+/-0.32 m) and 4 m wide, centred on the start pose.

Lap counting: every time a car enters or leaves the zone, its toggle count goes up by 1. Cars start inside the zone, so leaving and coming back is 2 toggles, i.e. one lap. A car's lap time keeps updating until it reaches 4 toggles (2 laps), then freezes.

Done when the ego car has collided, or every car has completed 2 laps.

Returns
Tuple (done, checkpoint_done):
  • done (bool): whether the episode is over.
  • checkpoint_done (np.ndarray of bool, shape (num_agents,)): whether each car has finished 2 laps.

Draw the environment in a pyglet window.

Scroll to zoom and click-drag to pan. The window shows the map, the cars, the frame rate (bottom-left) and lap information. The window is created on the first call.

Parameters
modeRendering mode:
  • 'human': sleep 5 ms after each frame to slow things down for viewing.
  • 'human_fast': render as fast as possible.
Exceptions
AssertionErrorIf mode is not one of the supported modes.
Note
The first call passes self.map_name to the renderer, which expects a path without an extension. That only works for a custom map given as a path. For the bundled names ('berlin', 'skirk', 'levine') it looks for e.g. 'berlin.yaml' in the current working directory, and if the 'map' kwarg was omitted, map_name does not exist at all.

◆ reset()

f110_gym.envs.f110_env.F110Env.reset ( self,
poses )

Start a new episode with every car at the given pose.

Clears the timer and lap-counting state, records the start poses (the finish zone is built around them), resets the Simulator, and then takes one step with zero input to produce the first observation.

Parameters
posesnp.ndarray of shape (num_agents, 3). Row i is [x, y, yaw] for car i.
Returns
Tuple (obs, reward, done, info), the same as step().
Note
Because reset() calls step() once, the physics has already advanced by one time step and current_time equals timestep.
lap_times and lap_counts are not cleared directly; they are recalculated by the step() inside reset().

◆ step()

f110_gym.envs.f110_env.F110Env.step ( self,
action )

Advance the environment by one physics time step.

Parameters
actionnp.ndarray of shape (num_agents, 2). Row i is [desired steering angle (rad), desired speed (m/s)] for car i.
Returns
Tuple (obs, reward, done, info):
  • obs (dict): the observation from Simulator.step() (scans, poses, velocities, collisions, ego_idx), plus lap_times and lap_counts.
  • reward (float): always equal to the time step. Design your own reward for training.
  • done (bool): ego collided, or every car has finished 2 laps.
  • info (dict): checkpoint_done, a per-car bool array of "finished 2 laps".
Note
lap_times and lap_counts in obs are the env's own arrays, not copies. They are updated in place, so an obs you keep from an earlier step will show later values. Copy them if you need a snapshot.
