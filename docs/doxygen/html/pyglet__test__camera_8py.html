Detailed Description

Standalone experiment for the pan / zoom camera later used by rendering.py: EnvRenderer.

Opens an 800x800 window with one coloured square. Drag with the mouse to pan and scroll to zoom about the cursor. The camera logic (left/right/bottom/top bounds plus a glOrtho projection) is the same approach EnvRenderer uses.

Run with: python pyglet_test_camera.py (the window opens as soon as the module is run or imported).
