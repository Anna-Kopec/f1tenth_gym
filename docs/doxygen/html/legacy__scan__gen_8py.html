Detailed Description

Script that generated legacy_scan.npz: reference LiDAR scans from the old C++-backed gym.

For each of three maps (vegas, berlin, skirk), it resets the old environment at 10 test poses (at the origin, yaw from -1 to 1 rad) and records the ego car's 1080-beam scan. The scans are saved to legacy_scan.npz under the keys vegas, berlin and skirk, and scan_sim.py's tests compare against them.

Warning
This script uses the old gym API (init_map(), update_params() with a C++ executable directory, reset() with a dict of poses), which the current F110Env does not have, and paths to a C++ build and maps that are not in this repository. It is kept as a record of how the data was made and will not run as-is.
